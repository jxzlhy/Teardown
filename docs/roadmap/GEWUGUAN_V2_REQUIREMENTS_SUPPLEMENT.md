格物馆 V2｜今日新增需求与深度优化任务书

项目名称： 格物馆（MUSEUM OF MACHINES）
执行工具： Zcode
文档版本： V2 Requirements Supplement
任务性质： 对现有 V2 主任务书进行补充，不覆盖、不替代现有主任务书。

⸻

第一章：项目整体目标与执行原则

1.1 本次任务的核心目标

本次任务并不是简单增加几个按钮或者调整一些 CSS，而是围绕格物馆的核心体验进行一次系统性的升级。

格物馆的核心价值在于真实、精致、可交互的 3D 展品。

因此，所有优化都必须围绕以下几个核心方向展开：

1. 展品真实性：确保 3D 模型的外观、内部结构、零件位置与真实设备相符。
2. 展厅沉浸感：让用户感受到自己正在参观一座数字化科技博物馆。
3. 交互专业性：让模型查看、拆解、测量、零件探索等操作更加自然。
4. 个人管理能力：让用户可以收藏、分类、评价和管理自己感兴趣的模型。
5. 质量持续优化：让用户评价逐渐成为模型质量诊断和改进的参考数据。
6. 自主迭代能力：允许 Zcode 根据项目实际情况自主发现问题、规划和执行后续优化。

1.2 最高优先级原则：真实性

本项目不是单纯追求视觉效果的 3D 展示网站。

禁止出现以下情况：

- 为了让模型看起来更复杂而随意增加内部零件。
- 将虚构的内部结构放置在真实零件位置。
- 在已有屏幕画面上叠加不属于该设备的虚拟屏幕。
- 将零件悬浮在错误的位置。
- 将不同型号设备的结构混用。
- 通过不合理的透视、透明材质或光效掩盖模型缺陷。

任何模型修复都必须优先参考可靠资料，并保留原始模型文件。

第二章：白天 / 黑夜双展厅系统

优先级：P1

2.1 功能定位

白天和黑夜不是简单的页面主题切换。

它们应该代表格物馆的两种不同参观环境：

- 白天：自然采光下的现代科技博物馆。
- 黑夜：夜间开放的沉浸式科技展厅。

两种模式都必须具有完整的视觉设计体系，包括页面背景、卡片、字体、边框、3D 场景、灯光、阴影、玻璃效果和交互状态。

重点是让用户切换之后，感受到展厅环境发生了变化，而不是仅仅看到背景颜色从白色变成黑色。

2.2 白天模式：DAYLIGHT GALLERY

设计定位

自然、明亮、通透、优雅、专业。

参考高端科技博物馆、现代建筑展览空间和产品设计展厅的视觉气质。

A. 页面环境

- 使用暖白、象牙白、浅灰白作为主要背景体系。
- 避免大面积纯白造成刺眼效果。
- 页面应具有适当的空间层次，避免所有区域都是同一种白色。
- 主要内容区域保持干净，减少无意义的装饰。
- 可以使用柔和的渐变营造自然采光效果。
- 卡片、面板和弹窗之间应具有明确的层级。

B. 材质表现

- 卡片采用轻量化半透明材质。
- 可以使用轻微的背景模糊效果。
- 边框采用低对比度浅色线条。
- 阴影应柔和自然，不能出现明显的黑色硬阴影。
- 悬浮工具栏应具有精致的玻璃质感，但不能过度透明，影响图标识别。

C. 3D 场景灯光

这是白天模式的重要部分。

不能只改变 HTML 页面背景，而不处理 Three.js 场景。

要求：

- 使用柔和的环境光作为基础照明。
- 配合合理的主光源，模拟自然采光。
- 可以使用适当的方向光表现模型表面细节。
- 控制高光强度，避免金属表面过曝。
- 保证深色零件、黑色屏幕和内部结构仍然清晰可见。
- 不同材质应具有合理的光照响应。
- 不允许通过过强的灯光改变模型原有材质观感。

D. 阴影

- 使用柔和阴影表现模型的空间关系。
- 避免模型像贴图一样漂浮在背景上。
- 阴影方向应与主要光源保持一致。
- 根据设备性能合理控制阴影质量。

E. 视觉氛围

白天模式应让用户感觉：

正在一座采光良好的现代科技博物馆中，近距离观察一件精密的科技展品。

不是普通后台管理页面，也不是传统电商商品详情页。

2.3 黑夜模式：NIGHT GALLERY

设计定位

沉浸、深邃、精密、安静、科技感。

参考高端科技展览馆、暗场产品发布会和专业机械展示空间。

A. 页面环境

- 使用深灰、墨黑、深蓝灰等颜色建立背景体系。
- 不建议所有区域直接使用纯黑。
- 背景应具有微妙的层次变化。
- 适当使用深色渐变，营造空间纵深。
- 卡片、弹窗、工具栏需要有清晰的边界。
- 避免大面积高饱和蓝色、紫色造成廉价科技感。

B. 玻璃与材质

- 悬浮面板采用深色半透明玻璃。
- 使用适当的背景模糊。
- 边框可以使用低亮度冷色线条。
- 选中状态允许使用克制的高亮效果。
- Tooltip 和菜单必须保证文字可读。
- 不允许为了营造玻璃效果而导致文字与图标对比度不足。

C. 3D 场景灯光

黑夜模式应重点优化 3D 展品的展示效果。

建议：

- 降低整体环境光强度。
- 设置合理的重点照明。
- 允许使用局部聚光表现展品的主体轮廓。
- 金属、玻璃、塑料等不同材质需要保持合理表现。
- 对内部拆解结构进行适当补光。
- 模型背面不能因为环境过暗而完全丢失细节。
- 光源变化不能造成模型颜色严重失真。

可以尝试类似高端产品发布会的展品照明方式，但必须保持专业和克制。

D. 重点展示效果

- 模型主体应该是画面的视觉中心。
- 可以使用柔和的轮廓光突出设备外形。
- 内部结构拆解时，适当提高零件可见度。
- 被选中的零件可以有轻微高亮。
- 不要让光效、粒子、动态背景抢走展品注意力。

  2.4 主题切换交互

切换入口应放在首页或现有全局主题控制区域中。

设计要求：

1. 提供明确的白天和黑夜状态。
2. 使用具有格物馆设计风格的图标或视觉标识。
3. 切换时采用平滑过渡。
4. 页面背景、卡片、字体、边框、阴影同步变化。
5. Three.js 场景的灯光和背景同步变化。
6. 已打开的弹窗、Tooltip、工具栏和零件面板同步适配。
7. 不允许切换时出现页面闪白、模型闪烁或明显布局跳动。
8. 用户选择的主题应按现有架构进行持久化。
9. 初次访问时遵循项目现有主题初始化策略。

  2.5 动画要求

可以考虑：

- 背景色渐变。
- 面板材质过渡。
- 场景灯光渐变。
- 图标轻微旋转或状态变化。

不建议：

- 整个页面突然黑屏再显示。
- 模型重新加载。
- 因主题切换重置相机位置。
- 因主题切换重置当前选中的零件。
- 使用过长的切换动画。

  2.6 验收标准

必须实际测试：

- 首页白天与黑夜模式。
- 首页向下滚动后的吸顶搜索栏。
- 模型详情页。
- 模型拆解状态。
- 零件选中状态。
- 所有工具栏二级菜单。
- Tooltip。
- 弹窗和信息面板。
- 3D 坐标辅助装置。

确保所有区域主题一致，且模型材质、结构和颜色没有发生错误。

第三章：模型详情页零件导航系统

优先级：P0

3.1 当前问题

当前详情页左侧存在纵向零件导航。

例如：

01
02
03
04
05
06

默认状态只显示零件序号。

鼠标移动到序号上时，才显示对应的零件名称。

例如：

06 电池

用户希望保留当前的紧凑展示方式，同时新增一种常驻显示完整零件名称的模式。

3.2 两种展示模式

模式 A：紧凑模式 COMPACT

保留现有设计：

- 默认只显示序号。
- 鼠标悬停时显示编号与名称。
- 选中状态具有明显反馈。
- 尽可能减少对 3D 模型视口的占用。

模式 B：展开模式 EXPANDED

新增完整显示方式：

01 外壳
02 显示屏
03 主板
04 摄像头
05 扬声器
06 电池

具体名称必须来自模型实际零件数据，不允许写死示例名称。

要求：

- 序号与名称同时显示。
- 不需要鼠标悬停即可识别。
- 当前选中零件应有明显状态。
- 支持较长的零件名称。
- 支持零件列表滚动。
- 切换模式时保留当前选中零件。

  3.3 模式切换入口

在零件导航区域设置紧凑 / 展开切换按钮。

要求：

- 图标语义明确。
- 提供 Tooltip。
- 切换动画自然。
- 展开后不能过度占据模型视口。
- 允许根据不同屏幕尺寸自动调整宽度。
- 移动端不能依赖 Hover 才能查看零件名称。

  3.4 零件映射准确性

这是本模块最重要的技术要求。

零件导航中的每一个编号都必须与实际 3D 对象正确关联。

禁止出现：

- 06 显示电池，但高亮的是主板。
- 点击零件后定位到错误对象。
- 零件名称和模型结构不一致。
- 同一个对象被错误重复编号。

第四章：详情页底部 3D 悬浮工具栏

优先级：P0

4.1 整体审计

先检查当前底部工具栏已经实现的全部功能。

可能涉及：

- 整机查看；
- 组装；
- 拆解；
- 视角切换；
- X 光查看；
- 测量；
- 模型复位；
- 零件显示 / 隐藏；
- 全屏；
- 其他项目现有工具。

以上是功能检查范围，不代表要求无条件新增所有按钮。

4.2 二级菜单遮挡问题

当前已知问题：

点击视角按钮后，会在工具栏上方弹出一个菜单，包含：

- 正面；
- 背面；
- 左侧；
- 右侧；
- 其他已有视角。

菜单保持显示时，鼠标移动到其他工具按钮上，Tooltip 会被视角菜单遮挡。

必须修复

建立统一的浮层管理规则。

明确：

- 工具栏层级；
- 二级菜单层级；
- Tooltip 层级；
- 弹窗层级；
- 零件信息面板层级。

Tooltip 应能够根据空间位置自动调整展示方向。

菜单靠近屏幕边缘时，应自动调整位置。

点击其他工具时，应有合理的菜单关闭或切换行为。

禁止出现多个菜单无序叠加。

4.3 视角工具

检查视角菜单：

- 视角名称准确。
- 图标统一。
- 当前视角有选中状态。
- 切换时动画自然。
- 不应导致模型突然跳转或丢失观察目标。

  4.4 X 光模式

检查是否可以真实呈现模型内部结构。

要求：

- 不能简单把整个模型变成透明。
- 需要考虑不同零件的透明度。
- 需要避免内部零件与外壳完全混在一起。
- 退出 X 光后恢复原有材质状态。
- 不得为了展示效果伪造内部零件。

  4.5 测量工具

如果项目已有测量功能，检查其准确性。

如果尚未实现，先评估模型比例和坐标数据是否支持真实测量。

要求：

- 支持清晰的起点与终点选择。
- 显示测量结果和单位。
- 支持取消和清除。
- 避免显示没有真实比例依据的精确数值。

第五章：3D 坐标辅助装置重新设计

优先级：P1

5.1 当前问题

详情页底部存在一个类似雷达盘的多重圆环坐标装置。

用户认为目前的设计不够美观，希望重新设计。

5.2 设计方向

不要仅仅调整颜色和透明度。

需要重新考虑它作为 3D 空间辅助装置的定位。

可以尝试：

方案 A：精密刻度式

- 细致的刻度线。
- 简洁的 XYZ 轴。
- 精密仪器的视觉语言。
- 克制的金属或玻璃质感。

方案 B：悬浮坐标式

- 简洁的空间坐标轴。
- 轻量半透明圆环。
- 柔和的高亮。
- 更强的科技展厅氛围。

方案 C：极简方向式

- 减少多重圆环。
- 保留 XYZ 方向。
- 降低整体占用面积。
- 让模型成为视觉中心。

Zcode 应结合当前项目风格，选择最适合的一种方案，也可以融合多种方案。

5.3 功能要求

- XYZ 方向必须准确。
- 与模型旋转状态同步。
- 不遮挡模型。
- 不遮挡底部工具栏。
- 白天与黑夜模式都必须适配。
- 不增加无意义的持续动画。

第六章：个人模型收藏馆

优先级：P1

6.1 产品定位

搜索和收藏是两个不同的功能。

搜索负责发现模型。

收藏馆负责管理自己喜欢、认为值得研究或者以后想再次查看的模型。

建议建立独立的「我的收藏馆」。

6.2 收藏功能

模型详情页提供收藏入口。

用户可以：

- 收藏模型。
- 取消收藏。
- 查看收藏状态。
- 将模型加入指定分类。

收藏状态应持久化。

6.3 自定义分类

支持用户创建自己的分类。

例如：

- 最喜欢的模型；
- 内部结构优秀；
- 外观还原度高；
- 值得研究；
- 待优化模型；
- 以后再看。

支持：

- 新建分类；
- 修改名称；
- 删除分类；
- 调整分类顺序；
- 添加模型；
- 移除模型；
- 一个模型加入多个分类。

  6.4 收藏馆页面

建议提供：

- 分类导航；
- 模型卡片；
- 搜索；
- 排序；
- 评分展示；
- 备注展示；
- 收藏时间。

视觉上应保持与格物馆主站一致。

不能做成普通的后台管理表格。

第七章：模型评分体系

优先级：P1

7.1 基础五星评分

默认采用简单五星评价。

用户可以快速评价一件展品的整体表现。

评分必须与收藏状态独立。

7.2 高级细分评分

允许用户展开详细评价。

建议维度：

1. 外观还原度；
2. 内部结构还原度；
3. 零件完整度；
4. 材质与贴图表现；
5. 拆解展示效果；
6. 交互体验。

不要求所有维度必须评分。

用户可以只评价自己了解的部分。

7.3 个人备注

允许用户添加备注。

例如：

- 外观还原度很高。
- 电池位置可能不准确。
- 摄像头模组结构值得研究。
- 内部零件缺少部分细节。

这些备注属于用户个人评价，不得直接作为真实结构资料。

第八章：AI 模型质量诊断与优化系统

优先级：P1 / P2，分阶段建设。

8.1 核心理念

用户评分不只是为了展示。

未来应当能够成为模型质量改进的参考入口。

例如：

某个手机模型：

- 外观还原度：五星。
- 内部结构还原度：两星。
- 零件完整度：三星。

AI 可以根据这些反馈检查对应模型。

但不能仅仅因为用户给了两星，就直接修改模型。

8.2 质量诊断

AI 可以检查：

- 零件数量；
- 零件命名；
- 零件层级；
- 零件位置；
- 装配关系；
- 模型比例；
- 材质；
- 网格完整性；
- 内部结构；
- 模型资源性能。

  8.3 优化建议

AI 应当输出：

- 问题描述；
- 涉及零件；
- 当前表现；
- 参考依据；
- 建议修改方案；
- 预期效果；
- 风险说明。

  8.4 修改追溯

每次修改必须记录：

- 原始模型版本；
- 修改时间；
- 修改对象；
- 修改原因；
- 修改前状态；
- 修改后状态；
- 验证结果；
- 回滚方式。

  8.5 真实性约束
