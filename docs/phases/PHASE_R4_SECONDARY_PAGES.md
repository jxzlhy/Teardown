## 技术编年 `/timeline`：时序脊柱

原「四带网格卡片墙」→ **博物馆年廊**：

- 展区题衬线化（古典机械/机电时代/电子时代/数字时代，24px 900）+ mono 年代跨度 + 右侧「N 条目」计数；
- **连续脊柱**：`.tl-items::before` 垂直轴线（accent 渐变淡出），每条目菱形节点（tech 紫 / device 青灰），年份右对齐于轴左（64px 列）；
- 行式排布替代网格：行 hover 变展签底色 + 节点点亮 + 标题变 accent；带宽 `max-width:980px`（浏览器实测全屏行长过长后收敛）；
- 窄屏 ≤700px：轴线/年份列左移收窄。
- `.tl-band/.tl-item` 断言锚点保留；smoke「四带 + ≥80 事件」照常通过。
