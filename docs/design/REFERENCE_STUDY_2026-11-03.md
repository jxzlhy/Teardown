# 参考站调研 · 工程档案级拆解界面设计语法（2026-11-03）

> 输入：用户搜罗的 8 个同类 3D 拆解/装配交互站截图（B 站视频截图，均为「工程档案」气质的 Three.js 交互站）：
> ① MAVIC 3 PRO 三摄拆解（暗厅） ② VNT-16 涡轮增压器（白模展厅） ③ DJI OSMO ACTION 4（暗厅）
> ④ QUAD 4S 结构拆解（暗暖橙） ⑤ 行星发动机·深色 ⑥ 行星发动机·白模 ⑦ BENTLEY W12（暗厅） ⑧ VX-12T（暗青全息）
> 定位：`UI_UX_REFACTOR_SPEC.md` 体系下的新一轮「工作空间（设备详情页）升级」参考证据。
> 职责区分：本文只做模式提炼与采纳裁定；审计记 `UI_UX_AUDIT.md`；实施过程记 `docs/phases/PHASE_I_*.md`。

## 1. 八站共同设计语法（跨站不变量）

### 1.1 布局骨架：三区一底
- **顶栏**：返回 + 品牌行（mono 小字）+ 展品名（EN 大字 + CN 副标）；桌面端在标题右侧直接平铺 **3–4 枚关键规格 chip**（数值大、单位与中文标签小，上下两行结构）。右侧常驻：主题切换（暗夜/白模）、系统状态（SYSTEM READY / SYS NOMINAL / LIVE SIM）、帮助、主 CTA（导出/分享）。
- **左面板 = 部件索引（COMPONENT INDEX）**：mono 眉题 + 大号部件计数（如 `10`、`24 ASSEMBLIES`）；分组节头（字母/系统名 + EN 微标注，如 `A 压气机总成 · COLD SIDE`）；行结构 = 两位序号 + CN 名 + **EN 名第二行**（上下两行，不是三列同行）；行尾状态点（按子系统着色：VNT-16 冷端青/热端橙）。面板底部常驻操作（复位全机 / 全机拆解）或进度（`DISASSEMBLY 100%` / `80% 三维装配`）。
- **右面板 = 档案/控制（三型）**：
  - **A 档案型**（Mavic、Quad 4S、Bentley、VX-12T）：巨型型号字（EN）→ CN 全名 → 一段简介 → **2 列规格瓦片**（大 mono 数值 + 小标签）→ 系统标签组 → **MODEL NOTE 真实性声明卡**（Quad 4S/VX-12T：程序化重建、不代表官方内部结构）。
  - **B 控制型**（VNT-16 CONTROL DECK）：启动模拟主按钮 + 带右对齐读数的滑杆组 + 2×3 动作按钮阵（全部拆解/装回/半透明剖视/部件标注/自动环绕/重置视角）+ VIEW 视角 tab。
  - **C 遥测型**（行星发动机 MISSION CONTROL）：单一大读数（150 亿吨）+ 分段进度条 + 2×2 规格格 + LIVE TELEMETRY 行条 + 就绪度 4/4。
- **底部 dock**：居中胶囊，分隔线分组：`[主动作 拆解/组装] | [视角组 ISO/FRONT/SIDE/TOP 或 整机/X光/剖切] | [标注/自动旋转/截图] | [复位]`，部分带进度读数。
- **中央 3D**：模型永远是无遮挡主角；UI 挂四角，中轴留空。

### 1.2 底座（地面盘）——用户点名的重点
所有站的模型都站在一张「精密刻度盘」上：
- **Mavic 3 Pro**：大半径深色圆盘 + 多圈**虚线同心环** + 外缘橙→绿渐变光弧 + 放射刻度，如雷达/转台。
- **行星发动机**：盘面外圈密集刻度 + 一圈虚线环 + 内圈实线环，盘缘有分段弧块（工程分段感）。
- **Bentley / VX-12T / Quad 4S**：同心环（虚/实交替）+ 淡网格，VX-12T 为全息网格盘。
- **VNT-16（白模）**：极克制——只留柔和接触阴影 + 一圈淡环，白纸面上盘面几乎隐形。
- 共性：**盘面元素全是线（hairline），无面、无字**；亮度集中在模型脚下，边缘渐隐。

### 1.3 微排版体系
- EN 全大写微标注（mono、宽字距 .2–.34em）承担「系统名」：COMPONENT INDEX / STRUCTURE MAP / MISSION CONTROL / UNIT DOSSIER。
- **CN + EN 双语命名**：CN 为主、EN 为副（下一行小字），出现于清单行、3D 标签、面板标题。
- 大数字 = mono/黑体大号 + 单位小字 + 中文标签最小（三级同排）。
- 序号两位数（01…）贯穿：清单、3D 标签、面板编号——同一部件在三个界面里编号一致。

### 1.4 状态语言
- 系统状态右上角常驻（●SYSTEM READY / STANDBY / SYS NOMINAL），加载/运行中变色。
- 部件行状态点：在位/已分离/选中/告警 分色（青=冷端、橙=热端、灰=未参予）。
- 拆解进度以 **百分比读数** 常驻（dock 或清单底部），非只有滑杆。

### 1.5 真实性声明卡（与我们红线同构）
Quad 4S「MODEL NOTE」与 VX-12T「TIPS」都在档案面板内放一张**引线标注的声明卡**：说明哪些是程序化重建、哪些口径不可当真实。这与本馆「真实模型 vs 程序化示意」的透明度要求完全一致——值得吸收为固定版式（引用线 + 弱化底）。

### 1.6 双主题
- 暗厅：深空底 + 单 accent（青/橙/绿）+ 玻璃面板。
- 白模厅（VNT-16、行星发动机白模）：**暖纸白底 + 近白粘土材质模型 + 面板近白 + hairline 分隔 + 暗红/工程橙 accent**。两主题共享同一布局，只换材质与 token——证明「日厅=白模展厅」不只是换背景，还可以是模型呈现方式（我们受限于真实 GLB 材质，不换模型材质，但界面层可对齐）。

## 3. 本轮实施范围（对应 slices）

- **S1 调研沉淀**：本文 + `DESIGN_SYSTEM.md` 增补 §13（展陈空间组件模式）。
- **S2 底座升级（引擎）**：`engine.js` plinth 盘面重建（R1）——夜厅「雷达刻度盘」、日厅「纸面浅刻线」；保持六层几何骨架、`setPlinthTop` 接地、thumb 隐藏、无数字、reduced-motion 无动画。
- **S3 设备页三区升级**：顶栏规格 chip（R2）+ 左清单两行行结构（R3）+ infoPop 档案版式（R4）+ dock 进度读数（R5）；全部双厅 token 化；smoke 锚点（#ctxCard/#mpChips/#clipStrip/#topbar/#infoPop .spec .k 等）保留。
- **S4 验证**：`npm run build` + `npm run smoke` + `tools/hud-verify.mjs`（新：日夜双厅 1440×900 / 390×844 截图目检 + 控制台错误断言）+ impeccable detect。

## 4. 明确不做（防止过拟合参考站）

- 不照抄任何一家的配色（Mavic 的荧光绿、Quad 的橙、VX 的青都是它们的身份；本馆保持 `--acc` 换肤体系）。
- 不引入「启动模拟/发射」类虚构功能（我们有真实的拆解/机构演示，不伪造遥测）。
- 不把左清单塞搜索框（部件最多 ~20 个，搜索是过度设计；大厅已有搜索）。
- 不加常驻遥测假数据条（LIVE TELEMETRY 在本馆语境=造假，除机构演示真实读数外不做）。
