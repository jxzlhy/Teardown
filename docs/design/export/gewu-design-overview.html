品牌与命名

BRAND · 馆牌唯一事实源 src/lib/brand.js

格物馆 · MUSEUM OF MACHINES（2026-10-31 由「拆解馆」更名，决策记录 D-20261031-08）。更名的根据是项目已从单一拆解动作成长为「动作 × 知识 × 展览」三层：

层内容「拆解馆」覆盖？
动作3D 拆解 / 装配 / X 光 / 剖切 / 测量成立，但只是入口
知识20 项技术原理库、运行演示、两点测量不覆盖
展览技术编年（公元前 150 年—2026）、知识星图、代际对比、常设展 103 台不覆盖

「格物馆」的语义：取自《大学》「格物致知」——研究事物而获得知识。拆开机器是「格物」，原理库 / 编年 / 星图是「致知」。馆名从动作升维到目的，且三字结构与衬线巨字门厅完全同构。「拆解」降级但不消失：保留为全站核心交互动词（拆解按钮、拆解度、开始拆解、试试一键拆解）。

命名规则

  • 馆名只出现在：门厅巨字、导视条馆印、页脚、<title>、设备屏幕通知卡。禁止在按钮 / 表格 / 部件级 UI 复读馆名。

视觉定位

VISUAL THESIS · 深夜展馆 NIGHT WING × MISSION CONTROL

高端数字科技博物馆 + 未来科技展馆 + 沉浸式 3D 探索空间。一句话论点（第二轮重构定稿）：深夜开放的机械博物馆——设备模型是唯一发光体；UI 只做三类事：导视（导航 / 检索）、铭牌（名字与数据）、氛围（深空底 + 扫描线）。不是 SaaS 后台、不是电商、不是 AI Dashboard 模板。

三条铁律

克制
不堆特效，一屏一个焦点。玻璃面板、chips、表格维持既有 Token，不做二次装饰。
层级
信息按博物馆铭牌逻辑分层：编号 → 名字 → 读数 → 说明，逐级弱化。
真实
不掩盖模型几何 / 映射问题，不把程序化示意包装成官方真实内部构件。

大胆预算 frontend-design：boldness 花在一处

「大」只留给四处：3D 模型、衬线巨字馆名、焦点展台、开场演出。其余界面元素一律安静——深空底色上的玻璃面板与 mono 读数，构成馆内的安静导视系统。

展品编号语言 全馆贯通的连续编号

全馆统一 NO.001 三位编号，形成连续的博物馆编号语言：大厅焦点展台 NO.002 → 展签卡左上 NO.001 → 工作空间左 rail 序号 01 → 部件展签 08 / 14。编号一律 mono 数据层。

用色规则与换肤流程

  • 新颜色一律 color-mix 派生自 --acc / --bg-*，或使用状态色 Token；强调色仅做点缀，禁止大面积铺底；每设备只允许换 --acc。
  • 换肤流程：设备配置 accent → 引擎根元素写 --acc → 梯度自动派生。接入检查：与 #45e0ff 可区分、bg-0 上对比度达标、--acc-08 上文本 ≥ 4.5 : 1。
  • Bloom 在引擎 L0 画质档关闭；CSS 侧同样克制，禁止过曝光晕叠加。

MOTION TOKENS · CSS 微交互 / GSAP 编排 / 引擎 3D

时长与缓动 Token 禁止内联 transition 绕过

Token值语义
--dur-1.18s微反馈（hover / 按下 / 开关）
--dur-2.32s面板出入、浮层
--dur-3.6s大区块转场

三层职责边界 铁律

层负责不负责
CSS transition / animationhover、面板出入、装饰循环（扫描线 / 脉冲）任何 3D 相关
GSAP设备页开机时间线、UI 编排、文本 / 数字补间不接管 three ticker
引擎（自研缓动）相机 flyTo、爆炸 / 装配插值、呼吸浮动、待机自转不操作 DOM

禁止：同一元素同时挂 CSS transition 与 GSAP 补间；JS 手写 style.transition 绕过 Token。

面板进出 · 标准时序

面板进备注
顶栏 / rail / dockboot 时间线 0.5s · 依次 0.12s 错峰GSAP 只此一处；沉浸淡出 .35s
ctxCard 桌面右侧滑入 .34s滑出 .22s；切部件重触发
ctxCard 移动 sheet底部上滑grip 可关；不遮 dock
infoPop / tourNotefade .25s非模态
exploreDrawer右滑 .25sEsc / 遮罩可关
guide overlayfade .5sEsc 可关；主 CTA 显式

3D 侧节奏与降级

  • 相机过渡单段 0.6–1.2s；Tour 步间停留 1–1.5s；爆炸 / 装配整段 0.8–1.2s，不做逐件 stagger。
  • 待机自转 > 5s 无操作启动，速度以「读得清标签」为上限；呼吸浮动幅度 ≤ 设备高度 1%、周期 ≥ 4s。
  • reduced-motion 三层降级：CSS 压至 0.001ms；GSAP 跳过开场编排；引擎直达 / 停转——新动效必配 reduce 分支。

禁止模式

  • 长页视差 / 平滑滚动库不引入；不引入第二个 DOM 动效库（motion / anime / AutoAnimate 均不进）。
  • 弹簧缓动不用于错误提示；开场强制动画 ≤ 2.5s 且可跳过；无意义循环动画常驻必可关（L0 画质与 reduced-motion）。

Input / 滑杆胶囊输入 mono placeholder，聚焦 accent 描边 + 辉光；滑杆轨道 2px + accent 填充 --p，thumb 12px grab 态，0 态保留端点可辨识。
状态反馈Loading 分段真实进度（构建 → 下载 → 编译 → 装配）；Empty 一句话 + 指向动作，不放插画；Error 给恢复路径（重新加载 / 返回门厅），不道歉、给方案；Toast mono 胶囊 3s 自动退，与 clipStrip / sheet 共存时自动让位。

组件准入规则

INTERACTION & ACCESSIBILITY

动效原则

  • 动效回答操作：打开 / 收起 / 确认 / 切换必须让用户看清「什么变了」；非用户触发动效仅限开场演出与氛围层。
  • 一屏一焦点：页面加载只做一次编排（大厅 riseIn / 设备页 boot 时间线）。
  • 时长一律 Token、缓动一律 --ease-out；空状态前置校验（隔离模式未选中时 toast 指引，不静默失败）。
  • 深链 ?e/p/t 一等公民：任何状态改动经 syncUrl 回写（260ms 防抖）；切台废弃旧参数。

无障碍约定

  • 焦点可见：全站 :focus-visible 2px --acc 环 + 2px offset；Tab 顺序遵循 DOM（顶栏 → rail → dock → 浮层）。
  • 可退出：所有浮层有 Esc 路径 + 可点关闭；沉浸模式有显式退出键。
  • 触控目标：视觉 34–38px 的图标按钮以 padding 扩展至 ≥ 44 × 44 有效区；移动 sheet grip 高 ≥ 32px。
  • 对比度：正文 ≥ 4.5 : 1；HUD 装饰标注不做唯一信息载体（必配 tooltip / aria-label）。
  • 屏幕阅读器：图标按钮必配 aria-label；折叠组件用 aria-expanded；toast / 错误用 role="alert"。

移动端专项 390 × 844 基准

  • 画布可操作性优先：面板不长期遮挡模型主体；双指缩放 / 单指旋转由引擎控制，页面级禁止劫持 pinch。
  • 桌面 hover 能力（tooltip、卡片箭头）在移动端必有无 hover 等价路径（点按直达）。

3D 呈现规范

3D EXPERIENCE · 引擎与资产管线现行约定

取景与姿态

  • 归一化 targetWidth（米）+ normalize: full；frontAxis 声明正面轴；竖屏按宽高比修正取景距离（阶段 E 修复，主体不裁切）。
  • 地面接触：设备底面贴 y=0 展台，禁止悬空 / 穿模；进场相机缓推，主体占高 ≥ 70%、四周留白 ≥ 10%；flyToPart 特写距离 ≤ 部件对角线 3 倍。
  • 灯光冷光主调，禁三灯全开；白漆材质过曝压暗而非关灯，黑壳材质防自发光糊死。

材质 / 爆炸 / 标签

  • 材质 9 预设（matSilver / matGold / matScreen…），新材质先加预设再使用；屏幕一律 CanvasTexture 实时绘制；材质分区 ≠ 独立零件，匿名网格用 mapByPosition 位置聚类。
  • 爆炸方向沿真实装配路径（外壳沿法向、内构件沿抽拉方向），禁止「全部向上飞」；爆炸后不遮相邻标签；assembledPos 精确复位（切换 N 次状态不变）。
  • 程序化内构件与真实模型视觉风格一致，并在 UI 如实标注示意性质；labelOffsets 逐部件校准，两标签屏幕间距 < 18px 视为遮挡。
